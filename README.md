# Answer Markdown Exporter · 回答导出工具

一个独立、开源的 Edge 扩展，将当前页面已加载的 ChatGPT 回答保存为 Markdown 或 PDF。重点保留公式源码、代码缩进、表格，以及可读取的图片和图标。

本项目不是 OpenAI 官方产品，也不隶属于其他导出插件厂商。MIT 许可证仅授权本项目原创代码；不授予任何平台访问、商标或第三方内容的权利。

## 功能

- 回答完成后显示一组“下载 Markdown／复制／预览／导出 PDF”；生成、思考和工具进度块不显示按钮，展开历史思考也不会重复插入。
- 无图片时下载单个 `.md`；有图片或图标时下载包含 `answer.md`、`images/` 及必要说明的 ZIP。
- 预览读取实际导出的 Markdown，可查看源码及转换说明。
- 公式优先读取页面的 LaTeX 源码属性或 TeX 标注，保留内部空白和 Unicode 字符；缺失时明确说明。
- 保护代码语言、缩进、空行和内部反引号；简单表格输出 GFM，复杂表格回退为安全 HTML。
- 用户主动选择的多条已加载回答可合并导出；不自动遍历历史聊天。
- PDF 使用本地打印页。默认 A4 布局不显示浏览器网址页脚，并保留每页正文留白、表头和分页规则。

## 安装

需要 Microsoft Edge / Chromium **130 或更新版本**。

源码安装：

```sh
npm ci
npm run build
```

1. 打开 `edge://extensions`，启用“开发人员模式”。
2. 选择“加载解压缩的扩展”，选择本项目生成的 `dist` 目录。
3. 刷新原有 ChatGPT 标签页。

如使用发布 ZIP，先解压，再选择含 `manifest.json` 的目录。升级时在扩展管理页重新加载，然后刷新聊天页面。

## 使用

在已完成的回答下方点击对应按钮。带图 ZIP 解压后，请保持 `answer.md` 与 `images/` 的相对目录不变。复制的带图 Markdown 也需要配套该目录。

PDF 打印目标建议选择浏览器内置“另存为 PDF”；不同系统打印驱动可能将文字转成不可搜索的轮廓。默认打印布局已去掉自动网址、日期页眉和页脚；如果自行设置了打印边距，请同时取消“页眉和页脚”。本扩展不修改浏览器的全局打印设置。

看不到按钮时，可点击扩展图标检查节点数量和扫描错误。诊断不包含对话正文或完整对话链接。

## 保真与限制

Markdown 从当前渲染的页面内容重建，不保证还原最初整段 Markdown 的字面写法或网站全部布局。数学扩展和 HTML 表格需要阅读器支持。代码预览的渲染器可能在末尾补一个 LF；代码内部缩进和空行单独验证。

含绝对值竖线、块公式、合并单元格等内容的表格会使用 HTML，公式以原生 MathML 保存，并在 `annotation encoding="application/x-tex"` 中保留 LaTeX 源码。已验证本机 VS Code 默认 Markdown 渲染链及 Chromium 原生 MathML，不需要给编辑器增加自定义公式插件；禁用 HTML、过滤 MathML 或版本过旧的阅读器仍可能不显示。无法安全渲染或过大的公式保留源码并给出说明。普通 GFM 表格中的公式继续使用 `$...$`。0.1.7 及更早版本已经导出的文件需要重新导出，更新扩展不会改写旧文件。

图片支持 PNG、JPEG、GIF、WebP。最多 30 个不同资源、单图 8 MiB、总计 24 MiB，内嵌编码另有 3200 万字符限额。跨域、登录和临时地址限制可能导致图片无法保存，届时保留说明；页面未暴露真实地址的附件需要回原对话打开。Canvas、交互应用和未来网站布局可能需要额外适配。

支持当前 GPT 的点击放大图片按钮和没有 `pre` 的代码块。点击导出时会尝试加载因离开视口而暂时卸载的代码，并在本次导出中保存源码快照；最多处理 100 个代码块、等待 12 秒，快照合计最多 200 万字符。准备结束会恢复原滚动位置；切换对话时停止，不恢复旧页面位置。仍无法读取的代码会保留明确位置和说明。

## 隐私与权限

显式权限仅为 `clipboardWrite`，内容脚本仅匹配 `chatgpt.com` 和 `www.chatgpt.com`；没有 cookies、tabs、debugger 或全站权限。不调用模型 API，不发送测试问题，不上传聊天或导出文件。

仅在用户触发导出、复制或预览后，读取所选回答已引用的图片；同源请求沿用当前登录环境，跨域不附凭据。预览和打印仅显示已捕获的内嵌栅格图片，脚本与公式字体均随扩展提供。详见 [隐私说明](PRIVACY.md)。

## 开发与测试

开发使用 Node.js 24，依赖由 `package-lock.json` 精确锁定：

```sh
npm run check
npm test
npm run build
```

`build` 生成清洁的 `dist`，其中不要保存手写文件。测试使用本地合成内容，不需要用户账号，也不消耗模型额度。
